# DealRadar frontend

React + Vite + JSX with component-scoped plain CSS. No Tailwind or Bootstrap.

## Run
```bash
npm install
npm run dev
```

The homepage is styled to closely follow the supplied DealRadar reference: white storefront layout, charcoal top strip, green deal accents, compact category tiles, product grids and footer. The Price Tracker navigation item and price-tracking promotional panel are intentionally omitted from the MVP, as previously decided.

Product cards use CSS placeholder artwork and sample data. They are not live offers. Marketplace API integration, working search, wishlist actions and price comparison logic are future implementation tasks.
